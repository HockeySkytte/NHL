NHL Contracts API (v1)

The Hockey-Statistics Contracts API is a free, public JSON REST API covering NHL player contracts, year-by-year salary breakdowns, team salary cap summaries, expiring free agents, and dead cap penalties from 2010–11 through 2034–35 (including projected future contract years). No API key or authentication is required, and CORS (Access-Control-Allow-Origin: *) is enabled for browser applications.

Base URL & Format

{{ api_base_url }}/api/v1/contracts

  • All responses are UTF-8 JSON with camelCase field names and dollar amounts in USD.
  • Season parameters accept 20252026, 2025-26, 2025/26, or 2025 (and comma-separated lists like 2024-25,2025-26).
  • No silent fallbacks: if a player or team has no contract data for a requested season, null or an empty array is returned.

Data Sources

  • Primary source — NHLPA: Historical and active player compensation (AAV, total salary, base salary, signing bonuses, minor-league salary, and 1-way/2-way status) sourced primarily from NHLPA Compensation.
  • Supplemental sources: Official NHL.com & club announcements (signing dates, terms, future extensions) plus public hockey reporting (ProHockeyRumors, Sportsnet, TSN, Daily Faceoff) for buyouts, retained salary, bonus overages, and recent signings.
  • Derived fields: Standard CBA ELC/RFA/UFA status notes, projected future contract years, and team cap space (capCeilingUsd − combinedOneWayPlusPenaltiesUsd).

Usage Limits & Caching

  • Rate limit: {{ contracts_api_rate_limit }} requests per minute per IP address (fixed 60-second window).
  • Every response returns X-RateLimit-Limit, X-RateLimit-Remaining, and X-RateLimit-Reset (Unix timestamp).
  • Exceeding the limit returns HTTP 429 with a Retry-After header.
  • Responses include Cache-Control: public, max-age=300 — please cache locally when running batch scripts.

GET /api/v1/contracts/players
Try Live JSON ↗

Search and filter player contracts. When season is provided, returns season-level rows (with year-specific salary, base, and signing bonus) enriched with contract term/expiry metadata. When season is omitted, searches full contract records.

ParameterTypeDefaultDescription

seasonstring—Single or comma-separated seasons (e.g., 2025-26 or 20242025,20252026).
positionstring—C, L, R, D, G, or F (all forwards).
statusstring—Contract signing status: ELC, RFA, or UFA.
expiry_statusstring—Status upon expiry: RFA or UFA.
two_wayboolean—true for two-way contracts, false for one-way contracts.
activeboolean—true to restrict contract-level search to currently active deals.
min_aav / max_aavnumber—Minimum / maximum AAV in USD (e.g., min_aav=8000000).
sortstringaav_descaav_desc, aav_asc, name_asc, end_year_asc, end_year_desc.
limit / offsetinteger50 / 0Pagination controls (max limit=200).
Example Request

Usage Examples

Python (requests)
import requests

BASE = "{{ api_base_url }}/api/v1/contracts"

# 1. Look up a player's multi-season average cap hit
r = requests.get(f"{BASE}/players/8477492", params={"season": "2022-23,2023-24"})
print(r.json()["summary"])

# 2. Fetch a team's cap summary & 1-way roster
team = requests.get(f"{BASE}/teams/ANA", params={"season": "2025-26", "two_way": "false"}).json()
print("Cap Space:", team["summary"]["projectedCapSpaceUsd"])
for p in team["roster"][:5]:
    print(f"{p['playerName']}: ${p['aavUsd']:,.0f}")
JavaScript (fetch)
const BASE = "{{ api_base_url }}/api/v1/contracts";

// League-wide cap space leaderboard for 2025-26
const res = await fetch(`${BASE}/teams?season=2025-26&sort=cap_space_desc`);
const { data } = await res.json();
console.table(data.slice(0, 5).map(t => ({
  team: t.team,
  capHit: t.combinedOneWayPlusPenaltiesUsd,
  capSpace: t.projectedCapSpaceUsd,
})));
curl
# Top 10 pending 2026 UFAs by AAV
curl -s "{{ api_base_url }}/api/v1/contracts/expiring?year=2026&expiry_status=UFA&limit=10" | jq '.data[] | {playerName, signingTeam, aavUsd}'

# Search players by name
curl -s "{{ api_base_url }}/api/v1/contracts/players?q=sennecke&season=2025-26" | jq .
R (jsonlite)
library(jsonlite)

url <- "{{ api_base_url }}/api/v1/contracts/teams?season=2025-26"
cap_tbl <- fromJSON(url)$data
head(cap_tbl[, c("team", "combinedOneWayPlusPenaltiesUsd", "projectedCapSpaceUsd")])
