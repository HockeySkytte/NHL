## Run it

```powershell
cd nhl_rust
cargo run          # serves on 0.0.0.0:5000 (PORT env overrides)
cargo test
```

Templates/static are read from `../app/templates` and `../app/static` by
default (the shared Flask tree); override with `TEMPLATE_DIR` / `STATIC_DIR`.
About-page content lives in `nhl_rust/data/about.json`, extracted from the
Flask module.

## Headline stack

- **axum** + tokio (web), **minijinja** (Jinja templates), **reqwest** (NHL APIs / PostgREST), **moka** (TTL caches)
- Supabase via raw PostgREST HTTP + GoTrue admin API (no SDK)
- XGBoost inference: one-time Python conversion of `Model/*.pkl` → compact JSON (via `Booster.save_raw` + calibrated base), scored by a **pure-Rust tree walker** (`src/models/xg.rs`) — no native xgboost library needed; see `scripts/export_models_for_rust.py`
- Stripe via **raw HTTP** to `api.stripe.com` (checkout/portal sessions, webhook with HMAC verification) — no SDK, consistent with the raw PostgREST/GoTrue approach

All `scripts/*.py` remain Python; the Rust app shells out to them for admin jobs, and Render cron jobs keep running in a Python-enabled runtime image.
